
# Система формування та перегляду розкладу занять

## Опис

Навчальний проєкт інформаційної системи для автоматизації формування, перевірки та перегляду розкладу занять.

## Основні користувачі

- Студенти
- Викладачі
- Працівники деканатів
- Адміністратори

## Мета проєкту

Автоматизувати формування, перевірку та перегляд розкладу занять, зменшити кількість конфліктів.

## Заплановані можливості

- Формування розкладу занять
- Перегляд розкладу
- Перевірка конфліктів
- Поступове підключення зовнішніх інформаційних систем

## Технологічний стек

- C#
- .NET 10
- Git
- GitHub

## Статус проєкту

Проєкт перебуває на початковому етапі організації репозиторію. Програмна реалізація буде виконуватися в наступних лабораторних роботах.

## Структура проєкту

- `src/` — вихідний код
- `tests/` — тести
- `docs/` — документація
- `README.md` — опис проєкту
- `.gitignore` — правила виключення файлів із Git
- `.editorconfig` — правила форматування

## Робота з репозиторієм

Issue → Branch → Commit → Pull Request → Review → Merge
